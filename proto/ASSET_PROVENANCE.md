# Asset provenance

This prototype bundle imports no third-party binary art, audio, fonts, logos, or market data.

- Charts: deterministic SVG generated locally by `shared.js` / `learning-engine.js`.
- Icons: Unicode glyphs and CSS primitives.
- UI: original HTML/CSS assembled for this prototype iteration.
- Canonical names and learning contracts: extracted from the user-supplied Signal Arena source archive.
- External repository links in the specifications were treated as design references only; no code or assets were copied into this bundle.

A separate license review remains required before importing any external repository asset into production.
