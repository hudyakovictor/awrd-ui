# 4. ИНДИКАТОРЫ КАК КАРТЫ-СНАРЯЖЕНИЕ (ответ на «придумать использование индикаторов»)

База в репо: `IndicatorsLab`, `M-10 Before/After Compare` (график до/после индикаторов), `G-05 Estimate`, `M-21 Holographic Cards` (визуал карт), `StrategyConstructor` (нодовая логика).

**Концепт: индикатор — это линза, которую игрок «надевает» на график, а не кнопка сигнала.** Подтип карт «Линзы» (не смешивать с 40 каноническими Skill Cards — те остаются решениями/навыками):

1. **Слоты Analyst Desk:** на стол можно надеть максимум 3 линзы — по одной в слот **Тренд-фильтр** (SMA/EMA), **Триггер** (RSI/Stoch/MACD), **Линейка риска** (ATR/BB). Это интерфейсное воплощение канона C29 «один фильтр + один триггер + один измеритель». Две линзы одной семьи физически не встают (слот занят) — обучение «RSI+Stoch = самообман» зашито в UI, а Indicator Cult ранга II — бой, где рука намеренно собрана из дублей.
2. **Уровни линзы:** **I Автопилот** — линза сама подсвечивает состояние и объясняет (worked example); **II Настройка** — игрок выбирает период/параметры под таймфрейм задачи (C21, C25), неверная настройка = мусорный сигнал прямо на графике; **III Внутренний глаз** — линза «разбита»: игрок оценивает значение на глаз (M11/G-05), допуск ±5 RSI-пунктов / ±0.3×ATR. Уровень III = требование для экзамена C29 и всех боёв рангов II+.
3. **Деградация линз (анти-Indicator Cult):** в 15% задач Analyst Desk линза даёт сигнал против структуры цены. Правильное действие — приоритет структуры (E40: «структура важнее паттернов»). Слепое следование линзе = штраф с разбором.
4. **Экономика:** линзы выдаются главой C бесплатно (не покупаются — канон «карта выдаётся только уроком»); косметика линз (скины расчерчивания) — из аркадного лута.

# 7. ИНТЕГРАЦИЯ С CORE LOOP (v2)

Такты цикла → механики: **[1] Учу** = урок + M17-разведка → **[2] Применяю** = M01–M15 по миксу фазы (§2) → **[3] Разбор** = встроенный debrief + M16-калибровка → **[4] Закрепляю** = adaptive-планировщик подаёт recall через M02/M03/M11 (лёгкие форматы — намеренно: повторение дешевле нового) → **[5] Доказываю** = mastery-gate (4 чистых × 3 контекста × 2 сессии) → **[6] Сражаюсь** = M22 на ассетах BattleCards/BossCodex → **[7] Расту** = дерево в профиле → **[8] Враг возвращается** = M22 ранги II/III, пост-гейм M23. Аркады — межтактовые паузы-награды. Журнал M24 — сквозной, растёт от 3 полей (A7) до полного аудита (J97).
